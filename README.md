# DeepPurge

A native GTK3 system-wide software uninstaller and residual config purger for Linux (Zorin OS / Ubuntu / Debian).

### Features
* Unified inventory: Flatpaks, Snaps, AppImages, native DEBs, and local binaries.
* Real-time search filtering.
* Deep removal: packages, configs, caches, systemd units, and desktop entries.

### One-Line Install
```bash
curl -sSL https://raw.githubusercontent.com/mschwachter/DeepPurge/main/install.sh | bash
```
